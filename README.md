Overview
An advanced Question-Answering system that allows users to upload their own PDF documents. It dynamically extracts text, builds a Knowledge Graph on the fly, and uses Graph RAG architecture to provide highly accurate answers based solely on the user's uploaded content.

What is New in Version 2
Dynamic PDF Upload: Users can now upload any PDF document directly through the user interface.
On-the-fly Processing: The system extracts text from the PDF, chunks it, and builds a custom knowledge graph instantly without needing to change the code.
Session Memory: The application remembers the uploaded document and graph during the user's session, allowing continuous question answering.
